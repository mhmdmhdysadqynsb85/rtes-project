# RTES Project

## Online Food Ordering System

### Project Overview

This project was developed for the Real-Time Embedded Systems (RTES) course.

The system models an Online Food Ordering System using real-time and embedded system concepts including finite state machines, interrupt handling, RTOS task management, memory organization, scheduling analysis, and code optimization.

---

## Project Objectives

- Design a finite state machine (FSM)
- Develop an extended FSM (EFSM)
- Model parallel state machines
- Define a memory map
- Implement FSM logic in C
- Analyze memory usage
- Implement interrupt service routines (ISR)
- Design RTOS-based tasks
- Protect shared resources using mutexes
- Perform schedulability analysis
- Analyze worst-case execution paths
- Apply code optimization techniques
